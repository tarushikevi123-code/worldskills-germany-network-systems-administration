# Module C – Networking | Weilburg Enterprise Network

This section contains the two practical tasks completed for **WorldSkills Germany 2025 – IT Network Systems Administration, Module C: Networking**.

Both tasks were implemented and investigated using **Cisco Packet Tracer**. They are kept in separate folders so the original network implementation and the later troubleshooting exercise remain clear and independently documented.

> Independent educational portfolio work. This repository is not affiliated with or endorsed by WorldSkills Germany or the competition organizers.

## Task 1 – Network Configuration

Design and implementation of the Weilburg enterprise network, including:

- VLAN segmentation and inter-VLAN routing
- Layer 2 and Layer 3 EtherChannel using LACP
- Rapid PVST+ and spanning-tree root placement
- HSRP gateway redundancy and load sharing
- OSPF dynamic routing and default-route propagation
- Centralized DHCP and DNS
- NAT/PAT
- SSH device management
- Standard and extended ACLs
- Port Security

**Contents:** device configurations, network design, addressing plan, implementation notes, topology files, test plan and validation records.

[Open Task 1 – Network Configuration](Task-1-Network-Configuration/README.md)

## Task 2 – Network Troubleshooting

Recovery of the supplied multi-router topology after a simulated configuration attack. The work focused on restoring IPv4 ICMP reachability between the LANs, PCs, servers and the external server at `203.0.113.100`.

The investigation covered physical interface state, Ethernet speed and duplex, IPv4 addressing and subnetting, VLAN membership, OSPF adjacency and route propagation, DR/BDR election, ACL application and end-to-end connectivity testing.

**Contents:** recreated logical topology, addressing reference, chronological troubleshooting log, connectivity results and evidence guidance.

[Open Task 2 – Network Troubleshooting](Task-2-Network-Troubleshooting/README.md)
