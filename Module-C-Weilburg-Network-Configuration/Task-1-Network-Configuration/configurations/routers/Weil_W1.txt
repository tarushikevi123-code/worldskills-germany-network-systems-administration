01. DEVICE ROLE AND DESIGN SUMMARY
================================================================================

Weil_W1 is one of the two WAN routers serving the Weilburg site. It connects
the Weilburg Layer 3 core switch to the corporate network and the ISP. It is
intended to act as an OSPF Area Border Router between site Area 0 and corporate
Area 2. It also provides internet NAT/PAT for the internal VLAN networks and
applies the intranet access-control policy to traffic arriving from the site.

The captured configuration shows these roles and connections:

- GigabitEthernet0/0/0 connects to Weil_C1 using 10.11.3.2/30.
- Serial0/1/0 connects to the ISP using 195.198.11.1/30.
- Serial0/2/0 connects to the corporate network using 172.20.20.1/30.
- Loopback1 provides the router management/OSPF identifier address
  10.10.111.4/32.
- OSPF process 1 uses router ID 4.4.4.4.
- A static default route points to the ISP next hop 195.198.11.2.
- OSPF `default-information originate` advertises the default route.
- NAT overload uses the ISP-facing Serial0/1/0 interface.
- Named standard ACL `vlans` identifies the internal VLAN subnets for NAT.
- Named extended ACL `intranet` permits HTTPS to 192.168.66.200, denies HTTP
  to that host, and permits other IP traffic.
- ACL `intranet` is applied inbound on the Weilburg-facing interface.
- SSH version 2, local authentication and a VTY source ACL are configured.

Expected addressing from the official task specifications:

  Weil_C1 <-> Weil_W1
    Weil_C1 Gi1/0/1 : 10.11.3.1/30
    Weil_W1 Gi0/0/0 : 10.11.3.2/30

  Weil_W1 <-> ISP
    Weil_W1 Serial0/1/0 : 195.198.11.1/30
    ISP next hop         : 195.198.11.2

  Weil_W1 <-> Corporate network
    Weil_W1 Serial0/2/0 : 172.20.20.1/30

The competition task specifies that Weil_W1 is the faster of the two WAN
routers' ISP connections. It also specifies bandwidth values for the WAN
interfaces; the values shown in this capture are recorded in Section 04.

Weil_W1.
