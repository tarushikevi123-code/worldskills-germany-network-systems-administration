# Module C – Evidence Library

Store only sanitized screenshots and supporting evidence that demonstrate actual Packet Tracer configuration or behavior.

## Evidence rules

Keep the device/client identity, relevant command or test, and result visible. Do not include passwords, password hashes, keys, tokens or unrelated personal information. Use descriptive filenames and link each screenshot from the relevant test record.

Evidence should distinguish configuration from function: a configured command alone does not prove the expected network behavior.
