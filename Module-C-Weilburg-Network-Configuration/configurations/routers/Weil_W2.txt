01. DEVICE ROLE AND DESIGN SUMMARY
================================================================================

Weil_W2 is the second WAN router serving the Weilburg site. It connects the
Layer 3 core switch to the corporate network and the ISP. It participates in
OSPF Area 0 for the Weilburg site and Area 2 for the corporate-facing WAN link.
It also provides internet NAT/PAT for the internal VLAN networks and applies
the intranet access-control policy to traffic arriving from the site.

The captured configuration shows these roles and connections:

- GigabitEthernet0/0/0 connects to Weil_C1 using 10.11.4.2/30.
- Serial0/1/0 connects to the ISP using 195.198.11.5/30.
- Serial0/2/0 connects to the corporate network using 172.20.20.5/30.
- Loopback1 provides the router management/OSPF identifier address
  10.10.111.5/32.
- OSPF process 1 uses router ID 5.5.5.5.
- A static default route points to the ISP next hop 195.198.11.6.
- OSPF `default-information originate` is configured.
- NAT overload uses the ISP-facing Serial0/1/0 interface.
- Named standard ACL `vlans` selects the internal networks for NAT.
- Named extended ACL `intranet` permits HTTPS to 192.168.66.200, denies HTTP
  to that host, and permits other IP traffic.
- ACL `intranet` is applied inbound on the Weilburg-facing interface.
- SSH version 2, local authentication and a VTY source ACL are configured.

Expected addressing from the official task specifications:

  Weil_C1 <-> Weil_W2
    Weil_C1 Gi1/0/2 : 10.11.4.1/30
    Weil_W2 Gi0/0/0 : 10.11.4.2/30

  Weil_W2 <-> ISP
    Weil_W2 Serial0/1/0 : 195.198.11.5/30
    ISP next hop         : 195.198.11.6

  Weil_W2 <-> Corporate network
    Weil_W2 Serial0/2/0 : 172.20.20.5/30
    Corporate peer       : 172.20.20.6
