# Evidence Standard

This project uses screenshots and configuration extracts to demonstrate network behavior.

- Crop screenshots to the relevant Packet Tracer window or CLI output.
- Keep the device name, command and meaningful result visible.
- Do not include passwords, hashes, tokens, private keys or unrelated personal information.
- Use descriptive filenames and add a short caption.
- Prefer focused `show` command output over complete running-configuration dumps.
- Record the source device/VLAN, destination, protocol and traffic direction where relevant.
- Distinguish configuration from functional verification: an ACL in a configuration is not, by itself, proof that traffic is correctly permitted or denied.

Only include Packet Tracer projects and competition materials when public redistribution is permitted.
