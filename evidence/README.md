# Evidence

Add screenshots that demonstrate a specific configuration or test. Use descriptive filenames, for example:

- `module-c-dns-nslookup.png`
- `module-c-external-server-ping.png`
- `module-c-intranet-https-allowed.png`
- `module-c-intranet-http-blocked.png`
- `troubleshooting-before-fix.png`
- `troubleshooting-after-fix.png`

Avoid screenshots containing passwords, keys, tokens, personal information, or unrelated desktop content. Add a short caption in the relevant workstream folder explaining what each screenshot proves.
