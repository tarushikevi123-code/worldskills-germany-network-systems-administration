# Packet Tracer working files

Keep original competition starter files separate from your own working copies. Add a `.pka` or `.pkt` file to this repository only after confirming that redistribution is permitted and that the file contains no credentials or other sensitive material.

Suggested local filenames:

- `module-c-network-configuration-working.pka`
- `module-c-troubleshooting-working.pka`

The `.gitignore` excludes Packet Tracer files by default. If a file is approved for public redistribution, review it first and deliberately unignore it rather than committing it by accident.
